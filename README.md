# «Сказка» — десктопное приложение для учёта работы ветклиники
C# + Windows Forms, база данных SQL. Учебный проект.
- 11 форм: авторизация, регистрация, услуги, запись на приём, персонал, история болезней, питомцы, владельцы
- ведение шести справочников (добавление, удаление, редактирование), фильтрация по цене, дате, специальности, полу и живой поиск
- экспорт документов в Excel и Word: талон на приём, договор на ветеринарное обслуживание, ветеринарный паспорт
- валидация ввода (длина, допустимые символы, проверка логина) и выпадающие списки, привязанные к БД
